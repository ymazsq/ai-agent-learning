# Agent 学习地图（幕布大纲）

可直接复制到幕布中，粘贴后会按缩进生成层级。流程图与思维导图见 [agent-flow.md](./agent-flow.md)。

- Agent 学习地图
  - 一、一次请求的完整链路
    - 0. 启动
      - JSONL 回放恢复 messages
      - 记忆加载，过滤 supersededAt 的旧记录
    - 1. 输入与查询处理
      - 关键词拆分（中文需分词）
      - 关键词压缩（口语转检索词）
    - 2. 组装 messages
      - system 分层：基础层、输入层、工具调用层
      - 历史：滑动窗口保留最近 N 轮，超阈值按轮压缩，失败整轮回滚
      - 注入：RAG 片段（TOP_K，带来源编号）、相关记忆
      - token 预算：按需供给，不全量塞入
    - 3. 检索 RAG
      - 离线：文档切分（块大小影响召回）→ Embedding → BM25 索引（K1 1.5，B 0.75）
      - 在线：BM25 召回（精确词）+ 向量召回（语义相近）→ RRF 融合（只用排名）→ Rerank（只重排候选池，CANDIDATES 10）
      - 相关性阈值：待实现
    - 4. 调用模型
      - temperature 按任务选：抽取与结构化用低温，润色回答可调高
      - 流式逐块拼接 delta
    - 5. 分支判断
      - 返回文本 → 生成回答
        - 带引用
        - 无依据时拒答
      - 返回 tool_calls → 工具流程
        - 白名单外或校验失败：错误作为 tool 消息回传
        - 写操作：用户确认 y/N
        - 只读且安全：execFile 执行
        - 结果或错误以 tool 消息回传，带 tool_call_id
      - 最大步数：未超过回到第 4 步，超过则停止并告知
    - 6. 持久化
      - 会话逐行追加保存为 JSONL，可恢复
    - 7. 长期记忆写入
      - 抽取：固定 key 词表，低温度
      - 写入：同 key 覆盖，旧记录标记 supersededAt，保留历史
      - 已知限制：措辞不同导致重复或误覆盖
    - 8. 评估
      - 检索：Recall@K
      - 生成：引用正确率
      - 拒答：误拒与正确拒答
      - 记忆：跨会话正确率
      - 成本：每次请求 token 数
  - 二、各天练习对应位置
    - 模块一 Agent 核心（Day 1–10）
      - Day 1 调用 LLM API：messages 角色，temperature 与 token 计费
      - Day 2 流式与多轮：模型不保存历史，每轮重新发送
      - Day 3 上下文管理：截断丢信息，摘要丢细节
      - Day 4 结构化输出：json_object 只保证合法 JSON，必须做 schema 校验
      - Day 5 Function Calling：模型只生成参数，应用执行
      - Day 6 最小 Agent：tool_calls 与 tool 消息一一对应，压缩按轮切分，失败整轮回滚
      - Day 7 工具安全：校验 → 确认 → 执行，execFile 而非 exec，安全规则写在代码里
      - Day 8 System prompt 分层：基础层、规则层、运行时层分开管理
      - Day 9 会话持久化：JSONL 保存与恢复
      - Day 10 压缩策略对比：每轮摘要、滑动窗口、预算触发；滑动窗口在本次实验中最后一题答错
    - 模块二 RAG（Day 11–14）
      - Day 11 切分与向量检索：块大小影响召回，200 字 5/5，500 字 3/5
      - Day 12 带引用问答与拒答：带引用回答，无依据时拒答
      - Day 13 RAG 质量评估：Recall@K，引用正确率，误拒率与正确拒答率
      - Day 14 混合检索与 Rerank：BM25 精确匹配，向量语义相近，RRF 分数不可直接比较，Rerank 只能在候选池内重排
  - 三、学习重点
    - 1. Agent 循环：tool_calls 必须回传，必须限制步数
    - 2. 上下文：按轮压缩，失败整轮回滚
    - 3. 结构化输出：合法 JSON 不等于字段正确
    - 4. 工具安全：白名单、校验、人工确认
    - 5. RAG 质量：切分、召回、拒答一起评估
    - 6. 混合检索：BM25 与向量互补，RRF 融合排名
    - 7. Rerank：无法召回候选池之外的内容
  - 四、尚未闭环
    - Day 14 候选池实验（CANDIDATES=20）已跳过
    - 记忆去重问题记为已知限制
    - Module 1 遗留：复现"长对话爆上下文"
